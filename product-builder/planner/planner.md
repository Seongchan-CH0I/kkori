# 기획 문서
상태: 초안 / 수정일: 2026-11-08

## 1. 서비스 요약
- **이름**: 꼬리 (kkori)
- **한 줄 정의**: 매일 기술면접 질문 하나에 답하면, AI가 면접관처럼 피드백하고 꼬리질문을 던진다.
- **대상**: 신입·주니어 개발자 취준생. 처음엔 백엔드(Java/Spring, CS, DB, 네트워크)로 시작한다.
- **핵심 루프**
  ```
  아침  알림: "오늘의 질문"
  낮    답변 작성 → AI 피드백(스트리밍) → 꼬리질문
  주말  주간 약점 리포트 → 다음 주 질문 비중 조정
  ```
- **연속 기록**: 매일 답할수록 여우 마스코트 '꼬리'의 꼬리가 길어진다.

## 2. 기능 범위
| 단계 | 기능 |
|---|---|
| MVP | 오늘의 질문, 답변 피드백(스트리밍), 꼬리질문, 질문 알림, 연속 기록 |
| 2단계 | 주간 약점 리포트, 스터디 모드 |
| 3단계 | 음성 답변, 이력서 기반 질문 |
